# Foodle Noodle — KPI & Empathy App 2026

เว็บแอปภายในของ Foodle Noodle Co., Ltd. สำหรับติดตาม KPI รายแผนก, กรอกคะแนนรายเดือนพร้อม HR อนุมัติ และบันทึกการช่วยเพื่อน (คะแนน Empathy)

## 🔗 ใช้งาน
**https://vipada-pla.github.io/KPI-Dashboard/**

- เข้าสู่ระบบด้วยอีเมล (ระบบส่งลิงก์ไปที่อีเมล ไม่ต้องใช้รหัสผ่าน)
- ใช้ได้เฉพาะอีเมลที่ผู้ดูแลระบบเพิ่มไว้ในแท็บ "ผู้ใช้งาน"
- ข้อมูลเก็บในฐานข้อมูล Supabase (ไม่อยู่ใน repo นี้)

## สิทธิ์ผู้ใช้
| สิทธิ์ | ทำอะไรได้ |
|---|---|
| ดูอย่างเดียว | ดู Dashboard และรายการทั้งหมด |
| หัวหน้าแผนก | + กรอกคะแนน KPI, บันทึก/ยืนยันการช่วยเพื่อน |
| HR | + อนุมัติ/ส่งกลับคะแนน KPI |
| ผู้ดูแลระบบ | + เพิ่ม/แก้ไข/ลบผู้ใช้ |

ผู้ส่งอนุมัติคะแนนของตัวเองไม่ได้ และผู้บันทึกยืนยันการช่วยเพื่อนของตัวเองไม่ได้ (บังคับที่ฐานข้อมูล)

## ฟังก์ชัน
1. **Dashboard KPI** — การ์ดสรุป, ตารางคะแนนรายแผนก×เดือน, รายละเอียด KPI (กรองเดือน/แผนก), แนวโน้ม, ยอดขายเทียบเป้า, KPI ต่ำกว่าเกณฑ์, ข้อมูลที่ยังขาด
2. **กรอก KPI / HR อนุมัติ** — หัวหน้าแผนกกรอก 0–5 + หลักฐาน → HR อนุมัติ/ส่งกลับ → ขึ้น Dashboard + ประวัติทุกการกระทำ
3. **บันทึกช่วยเพื่อน / Empathy** — บันทึก → หัวหน้ายืนยัน → คะแนน Empathy รายคนรายเดือน (โบนัสสูงสุด +5)
