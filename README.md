# Foodle Noodle — KPI & Empathy App 2026

เว็บแอปภายในของ Foodle Noodle Co., Ltd. สำหรับติดตาม KPI รายแผนก, กรอกคะแนนรายเดือนพร้อม HR อนุมัติ และบันทึกการช่วยเพื่อน (คะแนน Empathy)

> แอปตัวจริงทำงานบน Claude Artifacts: https://claude.ai/artifact/Nk8NkQraStmNwSSJRvGfp9
> Repo นี้เก็บ **ซอร์สโค้ด** เป็นสำรองและประวัติการแก้ไข — ไม่มีข้อมูลคะแนนจริงของบริษัท

## ฟังก์ชัน (3 แท็บ)

1. **Dashboard KPI** — การ์ดสรุป, ตารางคะแนนรายแผนก×เดือน, ตารางรายละเอียด KPI (กรองเดือน/แผนก), แนวโน้ม, ยอดขายเทียบเป้า, KPI ต่ำกว่าเกณฑ์, ข้อมูลที่ยังขาด
2. **กรอก KPI / HR อนุมัติ** — หัวหน้าแผนกกรอกคะแนน 0–5 + หลักฐาน → HR อนุมัติ/ส่งกลับ (ผู้ส่งอนุมัติของตัวเองไม่ได้) → คะแนนที่อนุมัติขึ้น Dashboard อัตโนมัติ + บันทึกประวัติทุกการกระทำ
3. **บันทึกช่วยเพื่อน / Empathy** — บันทึก → หัวหน้ายืนยัน → คะแนน Empathy รายคนรายเดือน (โบนัสสูงสุด +5)

## กติกาคะแนน

- KPI แต่ละตัว 0–5 ตามระดับค่าเป้าหมาย (3 = ค่ามาตรฐาน)
- คะแนนแผนก = ค่าเฉลี่ย KPI สถานะ "ได้คะแนน" (ไม่นับ N/A / ไม่มีรายงาน / รอข้อมูล)
- ระดับ: ≥4 ดีมาก · 3–3.99 ได้ตามเป้า · 2–2.99 ต้องติดตาม · <2 ต้องปรับปรุง
- Empathy: ในแผนก 1 · ข้ามแผนก 2 · ปัญหาด่วน/คุณภาพ/ความปลอดภัย 3 · คู่เดิมไม่เกิน 2 ครั้ง/เดือน · โบนัสไม่เกิน +5/เดือน
